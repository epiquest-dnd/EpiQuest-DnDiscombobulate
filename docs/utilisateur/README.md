# Documentation utilisateur

Pour des personnes non techniques : utiliser le produit sans aide (§03-C).
Guides pas à pas illustrés ; chaque capture a un texte alternatif.

## Plan

### Pour tous
- Premiers pas : créer un compte, se connecter
- Aide-mémoire de la notation des dés
- Fonctionnalités d'accessibilité (clavier, lecteurs d'écran, vue textuelle de la carte, animations réduites)
- FAQ

### Maître du jeu
- Créer une campagne et inviter les joueurs (lien ou code)
- Dessiner une carte : grille, fond, décor, murs et portes
- Préparer une rencontre avec le bestiaire
- Ouvrir la vue joueurs sur un second écran
- Mener un combat : initiative, actions, ajouter un effet, corriger ou annuler
- Révéler des documents aux joueurs
- Notes, PNJ, lieux et quêtes

### Joueur
- Créer son personnage avec l'assistant
- Faire évoluer son personnage (montée de niveau, repos, inventaire)
- Lancer des dés depuis la fiche
- Rejoindre une campagne
- Utiliser l'application mobile
